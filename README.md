StockPulse - ระบบจัดการสต็อกสินค้า

เว็บแอปจัดการสต็อกสินค้าแบบหน้าเดียว (ไฟล์ index.html ไฟล์เดียว) พร้อมระบบแจ้งเตือนเข้า Discord ผ่าน Webhook เมื่อสินค้าใกล้หมดหรือหมดสต็อก

งานส่งอาจารย์

ฟีเจอร์
Dashboard แสดงจำนวนสินค้า จำนวนรวม สินค้าใกล้หมด และสินค้าหมด พร้อมกราฟ
กราฟวงกลมสัดส่วนสถานะสต็อก (In Stock / Low Stock / Out of Stock)
กราฟแท่งจำนวนสินค้าแยกตามหมวดหมู่
Inventory List รายการสินค้าทั้งหมด ค้นหาได้ ปรับจำนวน +1 / -1 ได้ทันที แก้ไขข้อมูลสินค้า และลบสินค้าได้
Stock In / Out บันทึกการรับเข้าและจ่ายออกสินค้าตามจำนวนที่ระบุ
Alerts Log ประวัติการแจ้งเตือนทั้งหมด
แจ้งเตือนเข้า Discord อัตโนมัติ เมื่อ เพิ่ม/แก้ไข/ลบสินค้า, เพิ่ม/ลดสต็อก, สินค้าต่ำกว่าจำนวนขั้นต่ำ หรือหมดสต็อก
ปุ่ม Send Summary ส่งสรุปสต็อกทั้งหมดเข้า Discord ในข้อความเดียว (รายการสินค้าหมดและใกล้หมด)
เก็บข้อมูลไว้ในเบราว์เซอร์ รีเฟรชหน้าแล้วข้อมูลและประวัติการแจ้งเตือนยังอยู่
พื้นหลังเคลื่อนไหว เครือข่ายจุดที่เชื่อมกันและตอบสนองต่อเมาส์ (ถ้าเครื่องตั้งค่า "ลดการเคลื่อนไหว" จะแสดงเป็นภาพนิ่ง)
เทคโนโลยีที่ใช้
HTML, CSS, JavaScript (ไม่ใช้เฟรมเวิร์ก ไม่ต้องติดตั้งอะไร)
Tailwind CSS (ผ่าน CDN) และ Font Awesome สำหรับไอคอน
HTML Canvas สำหรับพื้นหลังเคลื่อนไหว
Discord Webhook สำหรับส่งการแจ้งเตือน
localStorage สำหรับเก็บข้อมูลในเบราว์เซอร์
วิธีใช้งาน
ดาวน์โหลดไฟล์ index.html
ดับเบิลคลิกเปิดในเบราว์เซอร์ (ต้องต่อเน็ต เพราะโหลด Tailwind และไอคอนจาก CDN)
ตั้งค่า Discord Webhook
ใน Discord ไปที่ตั้งค่าช่อง -> Integrations -> Webhooks -> New Webhook -> Copy Webhook URL
เปิด index.html หาบรรทัดนี้ (อยู่ต้น <script> หลัก):
js
   const DISCORD_WEBHOOK_URL = "YOUR_WEBHOOK_URL_HERE";
แทนที่ YOUR_WEBHOOK_URL_HERE ด้วย URL ที่ copy มา แล้วบันทึกไฟล์
เปิดหน้าเว็บ กดปุ่ม +1 ในหน้า Inventory List ถ้าตั้งค่าถูกต้อง ข้อความจะเด้งเข้าช่อง Discord

หากไม่ตั้งค่า ระบบยังใช้งานได้ตามปกติ เพียงแต่ไม่ส่งแจ้งเตือนเข้า Discord (ดูข้อความเตือนได้ที่ Console ของเบราว์เซอร์ กด F12)

คำเตือน: ห้ามใส่ Webhook URL จริงลงใน repo สาธารณะ เพราะใครเห็นก็ส่งข้อความเข้าช่องของคุณได้ และ Discord อาจลบ webhook นั้นทิ้งโดยอัตโนมัติ ให้ใส่เฉพาะในไฟล์ที่ใช้งานบนเครื่องตัวเอง

ข้อจำกัด
ข้อมูลถูกเก็บในเบราว์เซอร์ของแต่ละเครื่อง (ไม่มีฐานข้อมูลกลาง) ล้างข้อมูลเบราว์เซอร์แล้วข้อมูลจะหาย และเครื่องอื่นจะไม่เห็นข้อมูลเดียวกัน
เมนูด้านข้างจะซ่อนในหน้าจอขนาดเล็ก (มือถือ)
